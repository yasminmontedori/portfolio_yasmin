
# Portfólio Profissional - Yasmin Montedori

## Nome da aluna
Yasmin Montedori

## Descrição do projeto
Este projeto consiste no desenvolvimento de um portfólio
acadêmico para apresentar meu perfil, projetos e habilidades
adquiridas durante o curso de Desenvolvimento de Sistemas.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- GitHub Pages

## Funcionamento do projeto
O site possui um menu de navegação que permite acessar
as seções Início, Perfil, Projetos, Habilidades e Contato.

Na seção Projetos são apresentados trabalhos desenvolvidos
durante o curso. A seção Contato possui acesso ao GitHub.

## Recursos novos adicionados
Foram adicionadas animações de hover nos cards dos projetos
e nas habilidades, além de uma seção de habilidades.

## Como os recursos foram implementados
As animações foram desenvolvidas utilizando CSS,
com as propriedades transition e transform.

Ao passar o mouse sobre um card, ele se desloca
verticalmente e sua sombra é ampliada.

A seção de habilidades foi construída com HTML e CSS,
utilizando Flexbox para organizar os elementos.

Também foi utilizado JavaScript para melhorar
a navegação do menu em dispositivos móveis.
